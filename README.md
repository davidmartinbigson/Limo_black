# Limo Black Canada — Premier Private Limousine & Chauffeur Service

A fully animated, Canada-focused luxury limousine & private chauffeur booking web application crafted with **Next.js 15 (App Router)**, **React 19**, **Tailwind CSS**, and **Framer Motion** — featuring both **Dark Mode & Light Mode** and **live Canadian street-address autocomplete**.

## Key Features

- **100% Canada-Oriented Experience**: Tailored for **Toronto & GTA (`YYZ`, `YTZ`)**, **Vancouver & Whistler (`YVR`)**, **Montréal & Mont-Tremblant (`YUL`)**, **Calgary & Banff (`YYC`)**, **Ottawa (`YOW`)**, **Québec City (`YQB`)**, **Edmonton (`YEG`)**, **Halifax (`YHZ`)**, **Niagara-on-the-Lake**, **Muskoka**, and **Kelowna**.
- **Live Google-Maps-Style Canadian Address Search**: Type any street address, postal code, landmark, hotel, or airport across Canada to fetch live street-level Canadian suggestions (restricted to `CA`) with real GPS distance (`km`) and `CAD ($)` fare calculation.
- **Dual Luxury Theme (Dark Mode + Light Mode)**: Instant toggle in the header between **Obsidian Nocturne (Dark)** and **Architectural Alabaster (Light)** with persisted preference.
- **4-Step Reservation Checkout (`/book`)**:
  - All-Wheel-Drive Canadian Fleet (*Business Class*, *Electric AWD Class*, *First Class*, *Business Van/SUV*, and *Royal Stretch Limousine*).
  - Air Canada / WestJet / Porter flight telemetry, illuminated **Meet & Greet Digital Tablet** preview, heated cabin staging, GST/HST + 407 ETR toll inclusion, and privilege code `LIMOBLACK15`.

## Local Development

```bash
npm install
npm run dev
```
